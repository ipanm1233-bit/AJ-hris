Manajemen Absensi

Kelola data kehadiran sidik jari, pengkondisian data cuti/ekspedisi, dan cetak laporan payroll bulanan.

1. Import Raw Data Absensi

Unggah file Excel mentah (.xlsx) dari mesin sidik jari Anda. Pastikan kolom sesuai dengan format: NIK Karyawan, Nama Karyawan, Tanggal, Jam Kerja Masuk, dsb.

2. Export Laporan Kehadiran Terpadu (5 Sheet)

Tarik laporan matriks bulanan yang dikalibrasi otomatis dengan data cuti, lembur, uang makan ekspedisi, serta rekap denda keterlambatan.

3. Sinkronisasi Mesin Kantor

Agent pada komputer kantor mengirim log asli Solution X150 secara otomatis. Tombol di bawah memuat ulang hasil terbaru.
